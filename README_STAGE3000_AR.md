# NEXVARY FaceLab — Stage 3000

تم توسيع استوديو المعالم والتراث إلى 72 معلمًا موزعة على 9 دول: مصر، تركيا، الجزائر، السعودية، المغرب، تونس، إيطاليا، إسبانيا واليونان.

داخل التطبيق أضيفت التصفية حسب الدولة، البحث بالمعلم أو المدينة، والمفضلة الدائمة. توجد 72 صورة معاينة رسومية أصلية داخل الحزمة لتجنب إدخال صور فوتوغرافية غير موثقة الحقوق.

## إضافة حزمة صور فوتوغرافية مرخصة
ضع الصور في مجلد يحدده المتغير `FACELAB_HERITAGE_DIR`، وسمِّ كل صورة بالـ site_id مثل `eg_giza.jpg`. ثم أنشئ `licenses.json` اعتمادًا على `ai-server/heritage_backgrounds/licenses.example.json` وشغّل:

```bat
cd ai-server
python validate_heritage_pack.py
```

لا تعتبر الحزمة جاهزة للتوزيع التجاري إذا فشل فحص الترخيص.
