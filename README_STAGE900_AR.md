# NEXVARY FaceLab — Stage 900 — خزانة الملابس الذكية

تم إضافة قسم مستقل باسم **الملابس** إلى شريط التنقل السفلي. يحتوي على مكتبة من 72 لوك موزعة على 8 أقسام، مع دعم اللغات الست واتجاه RTL للعربية.

## طريقة الاستخدام
1. افتح **تحرير** واختر صورة الشخص، أو اختر الصورة من داخل قسم الملابس.
2. افتح **الملابس**.
3. اختر القسم ثم اللوك المطلوب.
4. اختياريًا اضغط **استيراد صورة الملابس** لاختيار قميص/بدلة/فستان من الهاتف.
5. حدد قوة التغيير ثم اضغط **تغيير الملابس بالذكاء الاصطناعي**.
6. النتيجة تضاف تلقائيًا إلى معرض FaceLab ويمكن حفظها أو مشاركتها من المحرر.

## المحرك
المسار الافتراضي يعمل محليًا باستخدام محرك Diffusers الموجود في FaceLab. عند إضافة صورة ملابس يمكن استخدام IP-Adapter المحلي إذا كان مفعّلًا. كما أضيف موصل اختياري لمحرك Virtual Try-On محلي عبر المتغير `FASHN_VTON_COMMAND`، دون ربط التطبيق بأي API مدفوعة.

> لا يتم تضمين أوزان FASHN أو أي مشروع VTON خارجي داخل الحزمة قبل تدقيق ترخيص الكود والأوزان بصورة مستقلة.
