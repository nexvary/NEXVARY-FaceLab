# NEXVARY FaceLab — Stage 9500

هذه المرحلة تعتمد رسميًا وضع الاستخدام الترفيهي الخاص وغير التجاري. أصبح محرك الأفلام متعدد المحركات ويختار المحرك الأنسب لكل لقطة: Wan 2.2 للمشاهد السينمائية العامة، MimicMotion لحركة الجسم، LivePortrait للوجه والتعبيرات، EchoMimic V2 للحديث بنصف الجسم، MuseTalk لمزامنة الشفاه، وFFmpeg للتجميع النهائي.

المحركات الخارجية وأوزانها لا تُضمّن داخل الحزمة؛ توضع في مجلد AI منفصل وتربط من خلال متغيرات البيئة الموجودة في `configure_entertainment_engines_windows.example.bat`.
