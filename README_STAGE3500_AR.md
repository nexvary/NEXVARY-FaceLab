# NEXVARY FaceLab — Stage 3500

تمت إضافة **استوديو الأفلام القصيرة** إلى التطبيق.

المسار أصبح:

صورة المستخدم → تعديل الوجه → اختيار الملابس → اختيار الخلفية/المعلم → Film Studio → السيناريو واللقطات → Motion Engine.

يدعم الاستوديو مدة من 30 ثانية حتى 5 دقائق ويقسم المدة تلقائيًا إلى لقطات قصيرة للحفاظ على ثبات الوجه والملابس والموقع بصورة أفضل. يوجد قفل للشخصية والوجه والملابس والموقع واستمرارية الإضاءة والكاميرا على مستوى مخطط الفيلم.

### محركات الفيديو المحلية
Stage 3500 يكتشف مسارات محركات محلية اختيارية من متغيرات البيئة:

```
FACELAB_COGVIDEOX_DIR
FACELAB_LTX_VIDEO_DIR
FACELAB_MUSETALK_DIR
FACELAB_FFMPEG
```

لم نضمّن أوزان نماذج فيديو عشوائية داخل الحزمة. يجب تدقيق ترخيص نسخة الأوزان نفسها ثم اختبارها على العتاد قبل تفعيل Render الفعلي. هذا يمنع الادعاء بأن ميزة توليد الفيديو جاهزة وهي لم تُختبر بعد على GPU حقيقي.

### البناء
```
gradlew.bat clean assembleDebug --stacktrace
```
