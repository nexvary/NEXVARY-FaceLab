# Stage 9500 Release

- Adopted Personal/Friends/Non-Commercial Entertainment profile.
- Added multi-engine film registry and per-shot automatic routing.
- Added Wan 2.2, MimicMotion, LivePortrait, EchoMimic V2 and MuseTalk engine slots.
- Dialogue shots prefer EchoMimic V2; body-motion shots prefer MimicMotion; close-ups prefer LivePortrait; general cinematic shots prefer Wan 2.2.
- Legacy external adapter remains as fallback.
- No paid inference API.
- Third-party weights are not bundled.
