# NEXVARY FaceLab — Stage 22500

هذه المرحلة تحول الـTimeline من بيانات JSON إلى محرر مرئي فعلي داخل الهاتف.

الوظائف الأساسية:
- بطاقات أفقية لكل Shot بعرض نسبي لمدة اللقطة.
- عرض معلومات الفيديو والحركة والصوت والترجمة داخل الـTimeline.
- اختيار اللقطة ثم تعديل مدتها عبر Trim.
- تحريك اللقطة يمينًا أو يسارًا داخل ترتيب الفيلم.
- Preview مباشر للـShot إذا كان ملف اللقطة قد تم توليده.
- Undo / Redo مستقل لتحرير الـTimeline حتى 30 حالة.
- تحديث Timeline من الخادم دون فقد اختيار اللقطة.

الخادم يعيد بناء start/end/duration بعد كل تعديل، ويحفظ plan.json بطريقة atomic مؤقتة ثم استبدال الملف.

مهم: لم يتم الادعاء بأن LivePortrait/MimicMotion/Wan GPU inference تم تشغيله في بيئة التسليم، كما أن بناء APK الكامل يعتمد على توفر Android SDK/Gradle dependencies.
